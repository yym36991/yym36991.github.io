
常用的HTTP路由和Web框架库
目前wfs_web使用github.com/gin-gonic/gin, wos_web使用的github.com/gorilla/mux
gin高性能，快的路由速率和高效的中间键支持。路由组，参数获取功能。


gorilla/mux功能强大，支持正则匹配路由,子路由器。

```
如：
router.HandleFunc("/api/wos/admin_api/deploy/{cid:[0-9]+}/proxies/{address:[a-zA-Z0-9.]+}", Handle(controller.GetProxy)).Methods(http.MethodGet)
子路由器：
adminRouter := router.PathPrefix("/api/wos/admin_api").Subrouter()
adminRouter.HandleFunc("/clusters/{cid}/gid_store", Handle(controller.GetGidStore)).Methods(http.MethodGet)
adminRouter.HandleFunc("/clusters/{cid}/store_online/{gid}/{address}/{enable}", Handle(controller.SetStoreOnlineStatus)).Methods(http.MethodPut)
```
